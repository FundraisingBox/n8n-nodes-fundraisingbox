# Instructions for Coding Agents

## Context

You can find relevant information about this project in the following files:

- [README.md](README.md): General project overview and usage instructions.

## Language

You **must** use English as the primary language for all code, comments,
and documentation.

## Commit and PR Convention

- This project uses [Conventional Commits](https://www.conventionalcommits.org/).
- Pull request titles must follow the same format as Conventional Commits, for example:
  `feat(config): add versioning support`.

## Completing Tasks

Your task is considered complete when:

- All tests pass
- Code is properly formatted
- Code is linted
- Documentation is updated

## General Philosophy

- Do things the n8n way
- Keep it simple
- Follow n8n guidelines on [code standards](https://docs.n8n.io/integrations/creating-nodes/build/reference/code-standards/), [ux](https://docs.n8n.io/integrations/creating-nodes/build/reference/ux-guidelines/), [error handling](https://docs.n8n.io/integrations/creating-nodes/build/reference/error-handling/) and [verification](https://docs.n8n.io/integrations/creating-nodes/build/reference/verification-guidelines/#package-source-verification)
- Avoid unnecessary complexity
- Use meaningful variable and function names
- Use interfaces to decouple components
- Have a look at the existing codebase to understand the project structure and conventions
